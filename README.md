# Bottleneck

## Factorio 2.1 temp fork
I am not the original author of this, I've just made some very minor changes to get this to work with 2.1

Copy the contents of this repo into your user mods directory exactly as `Bottleneck2_1` (case sensitive).

The bulk of the mod seems to be working BUT there are a few mod settings that are broken.  Factorio and the mod don't care so they're a low priority.


Factorio mod that tell you which machines are starved of ingredients
